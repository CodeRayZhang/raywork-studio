# v0.2.0 · 客户偏好记忆（预览版）

客户反复提出的表达要求，现在可以从批注整理为规则，确认后用于后续内容生成，减少每轮重新描述客户要求的操作。

## 新增

- 「客户偏好」视图：新增、确认、停用规则，可限定全部模块或单一模块。
- 批注来源保留；保存规则不会自动解决原批注或批准内容。
- 同品牌项目手动导入规则副本，导入后逐条重新确认。
- 内容版本保留生成时的规则快照，停用后旧版及交付清单仍可追溯。
- 真实模型输入仅包含适用的已确认规则；生成期间规则变化会阻止旧结果覆盖。

## 验证与升级

29 项本地自动化测试、Ruff 检查、JavaScript 语法检查通过；浏览器走通规则整理、确认、局部重写、跨项目导入及停用。详见 [验收记录](VALIDATION.md)。

保留原 `.state` 目录更新代码后重启即可；旧项目没有规则字段时按空规则处理。升级前可停服备份整个状态目录。无需新增模型依赖或向量数据库。

## 边界

本地模板模式只记录规则，不进行智能改写。真实模型请求由模拟测试验证，尚未实测内容质量或规则遵循率。规则由人整理并确认，无自动学习；同品牌匹配不是多租户权限系统。仍是单工作室、单进程原型，没有支付、自动发布或付费用户数据。

客户审稿页面不展示内部偏好记录，但管理端导出清单包含它们，请检查后再对外分享。
